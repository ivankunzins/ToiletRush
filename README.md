# 🚽 Toilet Rush: DON'T GET FLUSHED!

A colorful bathroom obstacle game inside a giant toilet. The player has 180 seconds to climb a five-floor circular route around the edge of the map. The center stays open to the sky so a huge boss can appear there after the ascent timer.

## Быстрый запуск в Roblox Studio

Rojo не нужен для обычного запуска.

1. Открой Roblox Studio и свой Place.
2. Включи `Game Settings → Security → Allow HTTP Requests`.
3. Открой `View → Command Bar`.
4. Открой `INSTALL.lua` из этого репозитория, скопируй его целиком и вставь в Command Bar.
5. Нажми Enter и дождись сообщения `[ToiletRush] ГОТОВО. Нажми Play.`
6. Нажми Play.

Установщик сам скачивает актуальные исходники из GitHub и пересоздаёт runtime-арену.

## Игровой цикл

`ЛОББИ → 10 секунд → 180 секунд подъёма → BOSS → победа → награды → следующий раунд`.

### Первый этаж

Первый этаж — спокойная и детализированная зона ванной: сантехника, декор, NPC и Robux Shop. На первом этаже нет препятствий. Лестница у внешнего края ведёт на второй этаж.

### Пять этажей

Все пять этажей идут **кольцами по краю круглой карты**. Центральная часть остаётся пустой и открытой в небо — именно там появляется босс.

- **Этаж 1:** чистая зона, магазин и знакомство с маршрутом.
- **Этаж 2:** первые движущиеся препятствия.
- **Этаж 3:** более плотная динамика.
- **Этаж 4:** сложный маршрут с несколькими типами препятствий.
- **Этаж 5:** самый сложный участок и кнопка аварийного смыва босса.

Препятствия не наносят урон: они блокируют путь и отталкивают. Падение во время раунда приводит к обычному респавну, после чего игрок продолжает прохождение.

## BOSS

После окончания 180 секунд **обычного смыва игроков больше нет**. В центре появляется высокий стилизованный босс-страж с округлым коричневым телом и руками.

- **30 HP**.
- Бьёт игроков на всех пяти этажах и снимает **12 HP** за атаку.
- Атака происходит примерно раз в **2,2 секунды**.
- Robux Blaster наносит **3 HP**, поэтому нужно **10 попаданий**.
- На всех пяти этажах в момент появления босса появляются камни.
- Всего появляется **30 камней**; каждый успешный бросок наносит **1 HP**.
- Камни можно бросать во время обычной фазы босса и пока он висит в сливе.

### Аварийный смыв босса

На пятом этаже находится кнопка `СМЫТЬ БОССА`.

После нажатия босс проваливается в центральный слив и примерно **10 секунд не атакует игроков**. Визуально он держится руками за край и пытается выбраться. После этого он возвращается и снова атакует.

Смыв босса не убивает его автоматически — игрокам всё равно нужно довести его HP до нуля.

## Очки и спасательный круг

- Обычная монета: **+5 очков**.
- Редкая монета: **+10 очков**.
- Для открытия покупки нужно собрать **30 очков за текущий раунд**.
- Lifebuoy стоит **25 сохранённых монет**.

## Robux Shop

На первом этаже есть:

- 🛟 Lifebuoy — 10 Robux;
- 🦺 Life Vest — 20 Robux;
- 🔫 Blaster — 40 Robux.

Для реальных покупок нужно создать три Game Pass в Creator Hub и вставить их IDs в `Config.RobuxShop`.

## Звук и визуал

Есть фоновая музыка, звуки монет, частицы воды, пузырьки, детали ванной, NPC, освещение и эффекты босса.

## Прогресс и сохранения

Сохраняются монеты, победы, раунды, серии побед, XP, уровни, ежедневная награда и достижения.

Для DataStore опубликуй игру и включи `Game Settings → Security → Enable Studio Access to API Services` при тестировании в Studio.

## Важно

GitHub содержит исходную версию игры. Roblox Studio используется для реального playtest.

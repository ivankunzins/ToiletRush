# 🚽 Toilet Rush: DON'T GET FLUSHED!

Collect coins, dodge bathroom hazards, buy a Lifebuoy in the final 20 seconds and survive the BIG FLUSH.

## Core loop
- 10-second intermission
- 180-second round
- Regular coins +1 and rare coins +5
- Rotating sweepers, bouncing soap, moving pipes and giant brushes
- Lifebuoy shop opens at 20 seconds remaining
- Lifebuoy costs 25 coins
- 10-second cinematic flush with shrinking water and spinning pull
- Lifebuoy owners orbit the drain and survive
- Survivors receive +40 coins and a win; flushed players receive +10 coins
- Results and immediate next round

## Engineering
Server-authoritative Luau, DataStore persistence, Rojo project layout, procedural arena generation, server-side purchase validation and isolated client cosmetic effects.

## Studio
Open a Roblox place, start Rojo and connect with `default.project.json`. Enable Studio API Services for DataStore testing. Publish before production testing.
